# Cutaway Garage poster

Cutaway Garage is a YouTube Shorts / Facebook Reels channel with code-rendered motion-graphics cutaways of car
mechanisms (engines, transmissions, drivetrains).

**Cutaway Garage poster** is the channel owner's private, single-user command-line tool. Once a day it uploads the
day's rendered clips to the owner's own YouTube channel through the YouTube Data API v3 and schedules them to go
public at fixed times. It has no other users, no website login, no public interface and does not read, store or
display any YouTube data belonging to anyone else.
